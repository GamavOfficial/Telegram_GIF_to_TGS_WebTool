v3 FIX

This version has its own GIF parser and LZW decoder. It does not depend on ImageDecoder, gifuct-js, CDN scripts, GitHub scripts, or any external JavaScript library. The selected GIF stays in the browser.

The TGS output is a raster-to-vector approximation. Simple transparent emoji/cartoon animations work best.
