Input support

GIF files are accepted through the browser's native file input. Conversion happens locally in the browser.

TGS output: gzipped Lottie JSON with a real .tgs filename. The download code does not use a text/data URL.

Telegram limits: TGS stickers are intended for 512×512, vector-only Lottie animation, up to 3 seconds and up to 60 FPS; this tool automatically uses the selected canvas and frame limits and warns when the generated file is above 64 KB.
