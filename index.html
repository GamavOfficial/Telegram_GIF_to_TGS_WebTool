Why this version?

This version does not use ImageDecoder.tracks.selectedTrack.frameCount, which caused the frameCount of null error shown in your screenshot. It uses the GIF frame parser gifuct-js instead.

The GIF is processed locally in the browser. The generated TGS is an approximate raster-to-vector Lottie conversion; simple transparent emoji/cartoon GIFs work best.
