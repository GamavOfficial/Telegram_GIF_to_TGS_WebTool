GIF files are accepted through the browser's native file input. No custom JavaScript click is used for the picker.

This tool does not upload the GIF to a server. Conversion happens in the browser.

Important: TGS is a Lottie vector format. This converter creates an approximate vector-style animation from raster GIF frames; simple emoji/cartoon GIFs are the best candidates.
